# AI QA Agent

A futuristic AI-assisted quality engineering dashboard built to showcase modern QA automation, API testing and intelligent test generation.

## Highlights
- AI-style test case generation from a target URL or API endpoint
- Risk scoring and test-plan dashboard
- Functional, API, security, accessibility and performance scenarios
- Interactive execution simulation with live results
- Playwright-ready sample suite
- GitHub Actions CI
- Responsive cyber/futuristic UI

## Stack
Vanilla JavaScript, HTML5, CSS3, Playwright, GitHub Actions.

## Run
Open `index.html` directly, or run a local static server.

```bash
npx serve .
```

## Automated tests
```bash
npm install
npx playwright install
npm test
```
